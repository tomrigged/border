# Render Border (Fabric, Minecraft 1.21.11, client-side)

- Toont de world border rondom je, op de rand van je render distance (alleen op jouw scherm).
- Bevat een ingebouwde texture "World border: blauwe strepen".
  Wisselen: toets B (instelbaar bij Besturing) of het commando /border. Uit = normale border, aan = blauwe strepen.

Vereist Fabric API. Bouwen via GitHub Actions (zie workflow), jar komt onder Artifacts.
