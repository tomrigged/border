# Render Border (Fabric, Minecraft 1.21.11, client-side)

Toont de vanilla world border op de rand van je render distance, rondom jou.
Alleen op jouw scherm; de echte server-border verandert niet.

## Jar maken via GitHub
1. Maak een nieuwe repo op GitHub en upload alle bestanden uit deze map.
2. Ga naar het tabblad **Actions** en wacht tot "build" klaar is (of klik "Run workflow").
3. Open de run en download onder **Artifacts** `renderborder-jar`.
4. Pak de zip uit; gebruik `renderborder-1.0.0.jar` (niet de `-sources` jar) in je mods-map.

Zonder Fabric API nodig; alleen Fabric Loader 0.18.1+ en Java 21.
